What is CI/CD?
Exact Definition

CI/CD is a software delivery practice that automates the process of integrating code changes, testing them, and deploying them to production quickly and reliably.

One-Line Definition

CI/CD automates building, testing, and deploying software.

CI

Continuous Integration

Definition

Developers frequently merge code into a shared repository where automated builds and tests verify the changes.

Purpose

Catch integration problems early.

CD

Two meanings:

Continuous Delivery

Every successful build is ready to deploy, but deployment to production requires manual approval.

Continuous Deployment

Every successful build is automatically deployed to production without manual approval.

CI/CD Pipeline
Exact Definition

A CI/CD pipeline is an automated sequence of stages that builds, tests, validates, and deploys software whenever code changes are made.

One-Line Definition

A CI/CD pipeline is an automated workflow that transforms source code into a running application.

Real-World Example

Suppose you update the login feature of a hospital application.

You create a feature/login branch.
You write and test your code locally.
You commit the changes.
You push the branch to GitHub.
You open a Pull Request.
A teammate reviews the code and approves it.
The branch is merged into main.
The CI pipeline automatically:
Checks out the code
Builds the application
Runs automated tests
Creates a Docker image
Pushes the image to a container registry
The CD pipeline deploys the new version to a staging environment.
After validation (or automatically, depending on the process), the application is deployed to production.

The entire flow happens consistently with minimal manual effort.
